1. Computer Systems

Hardware

Hardware means the physical parts of a computer that can be seen and touched.

Examples: keyboard, monitor, mouse, processor, printer and hard disk.

Software

Software is a set of programs or instructions that tells a computer what to do.

Software can be divided into system software and application software.

Input Devices

Input devices are used to enter data and instructions into a computer.

Examples: keyboard, mouse, scanner, microphone and webcam.

Output Devices

Output devices present processed information to the user.

Examples: monitor, printer, speakers and projector.

2. Data Representation

Computers represent data using binary digits. A binary digit is called a bit and can have the value 0 or 1.

Eight bits make one byte.

Example: binary 1010 is equal to decimal 10.

3. Algorithms

An algorithm is a sequence of steps used to solve a problem.

Algorithms can be represented using pseudocode or flowcharts.

START
INPUT length
INPUT width
area ← length × width
OUTPUT area
STOP

4. Computer Networks

A computer network is a group of computers and other devices connected so that they can communicate and share resources.

LAN

A Local Area Network covers a relatively small geographical area such as a school or office.

WAN

A Wide Area Network covers a large geographical area and can connect computers in different cities or countries.
